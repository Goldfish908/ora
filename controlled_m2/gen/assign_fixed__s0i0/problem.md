# assign_fixed__s0i0:工人-任务指派与启用费

有 3 名工人(W1、W2、W3)和 4 项任务(J1–J4)。每项任务必须恰好分给一名工人;每名工人最多承担 `cap[w]` 项任务。工人一旦被使用(至少承担一项任务),就要支付一次启用费 `fixed[w]`。目标是最小化总成本。

## 业务规则

1. **指派唯一**:每项任务恰好分配给一名工人。
2. **工人容量**:每名工人承担的任务数不超过其容量 `cap[w]`。
3. **启用激活**:工人 w 被使用(承担了至少一项任务)当且仅当该工人记为"启用"(启用是 0/1 决策),启用即支付 `fixed[w]`。不允许使用了却不启用,也不允许未使用却启用。
4. **目标**:总成本 = 指派成本(任务 j 分给工人 w 的费用 `cost[w][j]` 之和)+ 启用费之和,最小化。

## 数据

`data/params.json`:

- `workers`、`jobs`:工人与任务列表
- `cost[w][j]`:指派费用;`cap[w]`：容量;`fixed[w]`：启用费

## 输出要求

把结果写入本程序所在目录的 `solution.json`:

```json
{
  "objective": <总成本>,
  "assign": {"W1": {"J1": 0或1, ...}, ...},
  "active": {"W1": 0或1, ...}
}
```

同时在标准输出打印一行 `OBJECTIVE <总成本>`。
