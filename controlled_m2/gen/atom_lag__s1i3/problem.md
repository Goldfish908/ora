# atom_lag__s1i3:单仓单店补货计划(含运输时滞)

一个仓库向一家门店补货同一种商品,计划未来 3 期。仓库发货后**次期才到店**(运输时滞 1 期:第 t 期发出的货在第 t+1 期到达并可销售;第 3 期发出的货到不了,等于白付运费)。门店每期需求已知,可持有库存;需求必须当期满足,不允许缺货。每期发货的单位运费不同(越晚越便宜),库存有持有成本。目标是最小化总成本。

## 业务规则

1. **库存平衡**:第 t 期期末库存 = 上期期末库存 + 本期到货量 − 本期需求。**本期到货量 = 上一期的发货量**(第 1 期无到货)。第 1 期的"上期期末库存"为给定的期初库存。
2. **目标**:总成本 = 运费(第 t 期发货量 × `ship_cost[t]`)+ 库存持有成本(期末库存 × `hold_cost`),最小化。

## 数据

`data/params.json`:

- `demand[t]`:第 t 期需求(t=1..3)
- `init_inv`:期初库存
- `ship_cost[t]`、`hold_cost`

## 输出要求

把结果写入本程序所在目录的 `solution.json`:

```json
{
  "objective": <总成本>,
  "ship": [t1, t2, t3],
  "inventory": [i1, i2, i3]
}
```

同时在标准输出打印一行 `OBJECTIVE <总成本>`。
