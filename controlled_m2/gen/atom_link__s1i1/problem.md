# atom_link__s1i1:单期两仓三店分配(仓库启用费)

两个仓库(W1、W2)向三家门店(S1、S2、S3)配送同一种商品,只有 1 期。每家门店的需求必须**恰好**满足(从两个仓库发货之和等于需求,不多不少)。每个仓库发往各门店的发货量**合计**不超过该仓能力上限 `cap[w]`;**只要某仓库有发货(总量大于 0),该仓就必须记为"启用"并支付固定启用费 `fixed[w]`(启用是 0/1 决策;不允许有发货却不启用,也不允许未发货却启用)**。目标是最小化总成本。

## 业务规则

1. **需求恰好满足**:对每个门店 s,所有仓库发往 s 的发货量之和 = `demand[s]`。
2. **仓库发货能力**:每个仓库发往各门店的发货量**合计** ≤ `cap[w]`。
3. **启用激活**:仓库 w 发货总量 > 0 当且仅当该仓启用标志为 1,启用即支付 `fixed[w]`。
4. **目标**:总成本 = 运输成本(发货量 × `cost[w][s]`)+ 启用费(启用标志 × `fixed[w]`),最小化。

## 数据

`data/params.json`:

- `demand[s]`:门店 s 的需求
- `cap[w]`、`fixed[w]`、`cost[w][s]`

**JSON 形态**(务必按此读取,不要当下标数组):全部为以名称为键的对象——`demand["S1"]`、`cap["W1"]`、`fixed["W1"]`、`cost["W1"]["S1"]`。

## 输出要求

把结果写入本程序所在目录的 `solution.json`:

```json
{
  "objective": <总成本>,
  "ship": {"W1|S1": <数量>, "W1|S2": <数量>, ...},
  "open": {"W1": 0或1, "W2": 0或1}
}
```

同时在标准输出打印一行 `OBJECTIVE <总成本>`。
