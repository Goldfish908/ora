# atom_scope__s1i2:单期两仓三店分配(聚合计能)

两个仓库(W1、W2)向三家门店(S1、S2、S3)配送同一种商品,只有 1 期。每家门店的需求必须**恰好**满足(从两个仓库发货之和等于需求,不多不少)。每个仓库发往各门店的发货量**合计**不超过该仓的能力上限 `cap[w]`。目标是最小化总运输成本。

## 业务规则

1. **需求恰好满足**:对每个门店 s,所有仓库发往 s 的发货量之和 = `demand[s]`。
2. **仓库发货能力**:每个仓库发往各门店的发货量**合计** ≤ `cap[w]`(是整仓合计上限,不是每条线路各自的上限)。
3. **目标**:总成本 = 运输成本(发货量 × `cost[w][s]`),最小化。

## 数据

`data/params.json`:

- `demand[s]`:门店 s 的需求
- `cap[w]`、`cost[w][s]`

## 输出要求

把结果写入本程序所在目录的 `solution.json`:

```json
{
  "objective": <总成本>,
  "ship": {"W1|S1": <数量>, "W1|S2": <数量>, ...}
}
```

同时在标准输出打印一行 `OBJECTIVE <总成本>`。
