# flow_dir__s0i0:两厂一枢纽运输计划

两个工厂(A、B)生产同一种产品,全部货物先运到一个中转枢纽 H,再由 H 配送给两个需求点(D1、D2)。要最小化总成本(生产成本 + 运输成本)。

## 业务规则

1. **供应上限**:工厂 A 的出货量不超过 `supply["A"]`,工厂 B 同理。
2. **枢纽流量规则**:枢纽 H 的流入(A→H 与 B→H 之和)必须等于流出(H→D1 与 H→D2 之和)。H 不囤货。
3. **需求满足**:D1、D2 的到货量必须恰好等于各自需求 `demand["D1"]`、`demand["D2"]`。
4. **边容量**:每条边的流量不超过 `edge_cap[边]`。
5. **目标**:总成本 = 生产成本(工厂出货量 × `prod_cost[工厂]`)+ 运输成本(边流量 × `transp_cost[起点][终点]`),最小化。

## 数据

`data/params.json`:

- `supply`:各工厂供应上限
- `demand`:各需求点需求
- `edge_cap`:边容量,键形如 `"A->H"`
- `transp_cost`:单位运输成本,`transp_cost["A"]["H"]` 表示边 A→H
- `prod_cost`:各工厂单位生产成本

## 输出要求

把结果写入本程序所在目录的 `solution.json`:

```json
{
  "objective": <总成本>,
  "flows": {"A->H": ..., "B->H": ..., "H->D1": ..., "H->D2": ...}
}
```

同时在标准输出打印一行 `OBJECTIVE <总成本>`。
