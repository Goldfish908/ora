# inv_cap__s200i3__flip_storage_time:两产品库存-产能联合计划

某仓库管理两种产品(P1、P2)的未来 3 期补货计划。每期有已知需求,需要在满足产能与库容的前提下最小化总成本。

## 业务规则

1. **库存平衡**:每期期末库存 = 上期期末库存 + **本期**生产量 − 本期需求。第 1 期的"上期期末库存"为给定的期初库存。需求必须当期满足,不允许缺货,也不允许用未来期的产出满足本期需求。
2. **产能上限**:每个产品每期生产量不超过其产能。
3. **库容约束**:每期的下一期期末（即库存约束统一向前看一期，期末按 t+1 计，最后一期仍按本期计）,**所有产品**的库存占用体积之和(库存量 × 单位体积)不超过总库容 S。
4. **目标**:总成本 = 生产成本(产量 × 单位成本)+ 库存持有成本(期末库存 × 单位持有费),最小化。

## 数据

`data/params.json`:

- `demand[p][t]`:产品 p 第 t 期需求(t=1..3)
- `init_inv[p]`:期初库存
- `prod_cap[p]`、`hold_cost[p]`、`volume[p]`、`storage_cap`:常数
- `prod_cost[p]`:**可能是常数(各期相同),也可能是长度为 3 的列表(逐期成本,下标 t-1 对应第 t 期)——两种形态都要支持,代码里需判断类型**

## 输出要求

把结果写入本程序所在目录的 `solution.json`:

```json
{
  "objective": <总成本>,
  "production": {"P1": [x1, x2, x3], "P2": [...]},
  "inventory":  {"P1": [i1, i2, i3], "P2": [...]}
}
```

同时在标准输出打印一行 `OBJECTIVE <总成本>`。
