# setup_charge__s0i1:两产品生产-启动联合计划

某工厂计划两种产品(P1、P2)未来 3 期的生产。每期需求已知,生产有产能上限;只要某期某产品生产量大于 0,就必须支付该产品的一次性启动费(当期计一次)。目标是最小化总成本。

## 业务规则

1. **库存平衡**:每期期末库存 = 上期期末库存 + **本期**生产量 − 本期需求。第 1 期的"上期期末库存"为给定的期初库存。需求必须当期满足,不允许缺货。
2. **产能上限**:每个产品每期生产量不超过其产能。
3. **启动费激活**:某产品某期生产量 > 0 当且仅当该产品该期记为"启动"(启动是 0/1 决策),每启动一次支付该产品的启动费 `setup_cost[p]`。不允许不生产却计启动,也不允许生产却不计启动。
4. **目标**:总成本 = 生产成本(产量 × prod_cost)+ 库存持有成本(**本期期末**库存 × hold_cost)+ 启动费(启动 × setup_cost),最小化。

## 数据

`data/params.json`:

- `demand[p][t]`:产品 p 第 t 期需求(t=1..3)
- `init_inv[p]`:期初库存
- `prod_cap[p]`、`prod_cost[p]`、`hold_cost[p]`、`setup_cost[p]`

## 输出要求

把结果写入本程序所在目录的 `solution.json`:

```json
{
  "objective": <总成本>,
  "production": {"P1": [x1, x2, x3], "P2": [...]},
  "inventory":  {"P1": [i1, i2, i3], "P2": [...]},
  "setup":      {"P1": [0或1, ...], "P2": [...]}
}
```

同时在标准输出打印一行 `OBJECTIVE <总成本>`。
