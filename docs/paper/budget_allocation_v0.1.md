# 预算分配分析 v0.1:第 3 轮没有崩,多样性才是更好的预算去向

日期:2026-11-03
数据:三链现有运行记录,纯离线重放(零新 LLM 调用)

## 1. 动机与一个更正

此前(口头/纪要层面)有一个未实测的判断:"硬幻影细胞第 3 轮边际修复率
骤降,应把第 3 轮预算让给换路径重试"。本分析用三链全量记录实测了
逐轮边际修复率,**更正这个判断:臂级数据不支持"骤降"**。

## 2. 逐轮边际修复率(进入该轮且此前未成功的细胞中,本轮成功的比例)

| 轮次 | 链 A(无先验) | 链 B(代码惯例) | 链 C(语义惯例) |
|---|---|---|---|
| round 1(pass@1) | 6.8% (13/190) | 11.1% (21/190) | 21.6% (41/190) |
| round 2 | 29.9% (53/177) | 32.0% (54/169) | 36.2% (54/149) |
| round 3 | **29.8% (37/124)** | 18.3% (21/115) | **21.1% (20/95)** |

链 A 的第 3 轮修复率与第 2 轮持平(29.8% vs 29.9%);链 B/C 第 3 轮
有回落(32→18%,36→21%)但仍远非零。**"同路重试"在第 3 轮依然
值回票价**,不宜直接砍掉。

## 3. 预算-收益曲线(仲裁口径,witness 可行候选取 min 目标值)

| 配置 | 近似 LLM 调用量 | 成功率 |
|---|---|---|
| 单链 C × 3 轮 | ~434 | 57.9% |
| 三链 × 1 轮 + 仲裁 | ~570 | 33.2% |
| 三链 × 2 轮 + 仲裁 | ~1000 | 70.0% |
| 三链 × 3 轮 + 仲裁 | ~1450 | 80.5% |

读法:

1. **每调用效率**最高的是单链 C(57.9% / 434 调用);仲裁用更多调用
   买更高的绝对成功率——部署场景按"每百分点成功率的成本"选择工作点;
2. 多样性(加链)与深度(加轮)都在赚预算,但边际上**加链的
   回报更陡**(2 轮三链 70% 已超 3 轮单链 57.9%);
3. 结论:A4 的原始假设(砍第 3 轮)不成立。真正的预算优化方向是
   "先铺满多样性(链数),再加深轮数",以及用自进化提高单链的
   round-1 质量(把 21.6% 的起点抬高,后续所有轮的基数都受益)。

## 4. 对计划的影响

- A4 以离线分析收官,不做在线实验;
- "换路径重试"的价值已被三链仲裁以零额外 LLM 成本捕获(80.5%);
- 自进化(B 线)的定位因此更清晰:它优化的是所有链共享的起点
  (pass@1),杠杆最大。
