# 合体臂:P2 生成端 + guard v0.4 + 闸门 + witness 环(2026-11-03)

当前技术栈的全家桶对照臂:round-1 用 P2 生成(v0.2 先验+建模脚手架),
环内 guard v0.4 + 预求解闸门 + witness 反馈,≤3 轮,on 模式。
对照基线 B''(guard v0.3 + 闸门,round-1 为基线 pilot)。

## 1. 结果

| 指标 | B'' | 合体臂 | 解读 |
|---|---|---|---|
| pass@1(round-1) | 6.8% (13) | **11.1% (21)** | 生成端升级兑现 |
| after r2 | 34.7% (66) | **39.5% (75)** | 前两轮领先 |
| **after r3(终态)** | **54.2% (103)** | 50.5% (96) | **第三轮被反超** |
| crash 残余 | 18 | **10** | 全场最低(先验+v0.4 生效) |
| witness_infeasible 残余 | 63 | 79 | 语义层残余更多(见下) |
| guard 规则命中 | 508 | 19 | 先验在生成时刻已预防,guard 几乎不用出手 |
| LLM 修复调用 | 301 | 284 | 持平 |
| 求解调用 | 241 | 266 | +10% |
| 配对翻转 | — | combo-only 29 / B''-only 36 | 高方差 |

## 2. 为什么更好的起点没换来更好的终点

1. **环内方差主导**:温度 0.6 下两臂互相翻转 29/36 题,±7 题的终态差距
   在噪声量级内。逐轮曲线看,合体臂 r1/r2 一直领先,仅 r3 被反超——
   不是系统性退化。
2. **幸存者偏差**:P2 round-1 已带走 21 个"较容易"的成功,入环的 169 个
   细胞是更硬的残余(B'' 入环 177 个里含更多可修复的中等题);环的边际
   修复率天然更低。
3. **语义层瓶颈岿然不动**:两臂的 witness_infeasible 残余(63/79)都是
   最大失败类——生成端先验不碰语义,幻影只能靠环内 witness 反馈修,
   而 3 轮预算对硬幻影不够。

## 3. 最有价值的发现:两臂成功集合高度互补

**B'' 103 题 ∪ 合体 96 题 = 132/190(69.5%),交集仅 67 题。**

含义:
- 当前方法的能力上限(单样本路径)约 70%,远大于任何单臂成绩;
- 不同生成条件(priors+脚手架 vs 无先验)产生**多样化**的解题路径,
  失败不集中——这是"best-of-N / 种群"策略的直接证据:同一 harness
  跑两条多样化生成链、witness 裁决取真成功,预期接近 69.5%,而成本
  只是两份单臂(witness 判定是确定性的,仲裁零 LLM 成本);
- 这也为自进化的种群方向(agent population)提供了实证支持:多样性
  本身就是资产。

## 4. 下一步候选

1. **双链集成臂**(最便宜的大头收益):B''+合体两链并行,witness 仲裁,
   预期 ~69%;再进一步可用"先验/无先验"作为种群多样性源。
2. **语义层第 2 代 memory**:族级约定先验(如初始库存默认)攻 63–79 的
   witness_infeasible 残余——需族留出协议防泄题。
3. 硬幻影的环内预算分配:witness_infeasible 细胞在第 3 轮后的边际修复率
   骤降,考虑把第 3 轮预算让给"换一条生成路径重试"而非继续修补。
