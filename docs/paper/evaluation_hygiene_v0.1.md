# 评测卫生工作规范(Evaluation Hygiene) v0.1

2026-11-09 · 源于"dev 上提取 witness 规则后再测 memory 条款是否泄题"的讨论。
**每次设计/评审实验前必读。**

## 核心风险清单(时刻自问)

1. **教练裁判同源**:用 X 标定错误供学习,又用 X 判定修复效果。
   → 对策:主判定必须与学习信号独立(目标值匹配 vs witness);
   报告时**拆开统计**,警惕"只讨好裁判"的条款。
2. **参考答案非真值**:IndustryOR en_answer 错误率≥54%(三方互证);
   RetailOpt 参考值为 Gurobi 长限时(近似精确)。
   → 对策:不一致细胞分"更优/更差"两向报告;保守口径为主,
   case review 上修为附。
3. **变体过拟合**:dev(v0/v4)有效 ≠ 同族(v1-v3)有效。
   → 对策:两级晋升,gapcheck 必过;gen1 条款#8 是被拦的实例。
4. **留出污染**:F5-F8/IndustryOR 只终测,永不参与提议/调参/选择。
   → 任何"看看留出集结果再改一下"都是污染。
5. **单样本噪声**:重采样翻转率高达 75%(gen1 对照实测)。
   → 头条数字必须多种子+配对检验(McNemar);单样本只作中间参考。
6. **容差敏感**:判定阈值(1e-3)可能影响结论。
   → 已做 ε 敏感性(1e-4~5e-2 稳健),新指标引入时必做。

## 已落档的拆分验证(2026-11-09)

28%(无讨好裁判迹象);三臂幻影率均 69%→56%(真实减少语义错误)。

## 新实验启动前检查单

- [ ] 判定标准与学习信号是否独立?(若否,加独立判定并拆开报)
- [ ] 是否有留出集?它是否从未参与任何迭代?
- [ ] 是否多种子+配对检验?
- [ ] 参考答案的可靠性是否声明(更优/更差两向)?
- [ ] 容差/阈值是否做敏感性?
