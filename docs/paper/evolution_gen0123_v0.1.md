## 结果

### 基线(手工蒸馏 P3,已核实)

| 口径 | 数值 |
|---|---|
| dev40 单发 | 25.0% (10/40) |
| gapcheck60 单发 | 21.7% (13/60) |
| 全量 190 单发 | 21.6% (41/190) |
| 其中 F5-F8 留出族 | 20.0% |

"显著超过"的操作定义:dev40 成功率差 ≥ +10pp(40 题下约等于
多对 4 题,且超过逐题配对噪声带);"留出族不衰减":全量 190 中
F5-F8 成功率不低于 P3 的 20.0% - 5pp = 15.0%。

两点读法:
1. **同批对照下,P3 种子就是第 0 代最强**——此前手工蒸馏的条款组合
   不是随便配的;删除任一语义条款或改变块序都在掉点。这印证了条款
   内容本身的贡献,也给变异算子立了"必须打败亲本"的硬标杆。
2. **基线测量噪声**:P3 原始 pilot 文件在 dev40 上为 25.0%(10/40),
   本次同配置重测 35.0%(14/40)。温度 0.6 采样下 n=40 的批间摆动
   ~±7.5pp(1σ),两次测量差 10pp ≈ 1.3σ,属正常噪声。因此判据 (a)
   的参照系采用**同批 g0_seed 的 35.0%**,"显著超过"= 冠军 > 45%。
