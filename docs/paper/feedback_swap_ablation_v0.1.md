# 反馈置换消融:确定性反馈 vs LLM 自评反馈(190 全量) v0.1

日期:2026-11-10 · 数据:`runs/m1_presolve/m1_presolve_anchor_fb.jsonl`(完成)

## 设计(因果控制)

同一环路(m1_presolve_loop,含 guard+gate)、同一 round-1 pilot(裸)、
同预算(≤3 轮)。**唯一变量:语义失败时的反馈信号**。
- 对照(B″):witness 确定性违规明细(哪条守恒、哪个坐标、差多少)
- 置换(anchor):SAC-Opt 式管线——题面锚点抽取+代码锚点重建+LLM
  比较输出的 mismatch 清单(每轮 3 次 LLM 调用,预算不低于对照)

## 结果(190 细胞,failure_type 判定)

| 反馈信号 | exec | true success |
|---|---|---|
| **witness 确定性违规明细(B″)** | 87.4% | **54.2% (103/190)** |
| SAC-Opt 式锚点自评清单 | 57.4% | **28.4% (54/190)** |

**确定性反馈比 LLM 自评反馈高 +25.8pp(接近翻倍)。**

## 证据链闭合("确定性锚 > LLM 自评"四层)

| 层 | 证据 | 数字 |
|---|---|---|
| 复现 | SAC-Opt 自评 aligned 与实际失败的偏离 | 90% 假对齐(36/40) |
| 混合臂 | 给 SAC-Opt 补崩溃恢复层后 | 仍仅 12.5%(5/40) |
| 头对头 | Opt-Verifier 式 LLM 解侧评审 vs witness | 漏检 75%/误报 30% vs 0/0 |
| **因果置换(本实验)** | 同环路同预算只换反馈信号 | **28.4% vs 54.2%** |

四层相互独立,共同支撑:LLM 自评/互评不能作为优化建模的信任锚;
确定性重算(witness)反馈是修复环有效的因果来源。
