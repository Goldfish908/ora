# IndustryOR k=1/k=3 候选生成与选择结果

**范围：100 题，开发性新采样，不是 held-out。** 不叠加 memory 或额外 repair。k=1 与 k=3-first 共用 A。

## 主要指标

| 指标 | 数量 | 说明 |
|---|---:|---|
| 历史 z2 | 74/100 | 含执行修复的旧日志复算 |
| 上一轮完整管线 | 70/100 | 含有限 Witness/修复 |
| k=1 目标匹配 | 60/100 | A 单独生成，abs≤0.1 |
| k=3 selected 目标匹配 | 66/100 | 无参考答案选择器选出的实际输出 |
| k=3 oracle 目标匹配 | 70/100 | 仅候选池上界，不是可部署方法 |
| 选择器错过候选池 | 4 | oracle 匹配但 selected 不匹配 |
| k=1 业务正确 | 2 | 仅注册审计题 |
| k=3 selected 业务正确 | 3 | 仅注册审计题 |
| k=3 候选池业务正确 | 3 | 任一候选独立通过，非最终输出 |
| runner errors | 0 | 失败保留在分母 |

k=3 selected 相对 k=1 的差值：**+6**。oracle 相对 k=1 的差值为 +10，后者只说明候选池潜力，不能作为方法收益。

本轮 k=1/k=3 不做额外 repair，与历史含修复结果不是严格机制消融；模型 revision 和采样也不同。公开 COOPA 的 76/100 仅作同数据、同绝对误差口径的参考。单次开发采样不构成 SOTA 证明；若 selected 不超过该线，也不得用 oracle 替代。

## 可追溯性与限制

- 核验 300 份候选生成、97 份选择记录、24 份业务评分和 6 份执行源码快照。
- k=3 selected 不使用 `en_answer`；oracle 是事后分析，不参与选择。92 个未注册业务审计题仍保持 `business_unverified`。
- 本轮没有 memory、额外 repair 或跨题外环，因此结果只回答候选多样性和选择器的贡献。
