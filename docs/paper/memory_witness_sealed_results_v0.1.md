## 3. 失败层级

1. **候选作者过度保守**：101 题中 93 个关闭 guard、3 个证据拒绝，仅 2 个候选（195、199）。195 未激活；199 连续三轮拦截后仍无有效解，按协议拒绝部署。
2. **sealed 不能用反例纠偏**：dev/validation 中依赖独立反例晋升的样本无法获得同等修正，说明仅靠冻结作者并不足以泛化晋升机制。
3. **旧域资产不可直接迁移**：A2 的 RetailOpt witness 在 101/101 上均为 `unknown_schema` 并 fail-open，没有提供有效检查。
4. **参考噪声不可忽略**：8 个 sealed TSP 经穷举全部循环后与公开答案不一致，原始榜分与独立审计分必须并列，不能把不一致直接归为模型失败。

## 4. 与 validation 的关系

validation 的正收益没有自动迁移到 sealed。它支持“独立反例可修复变量类型错误”，但不支持“冻结作者可在新域无标签泛化”。后续改进应针对结构触发与候选验证机制，而不是继续扩大 sealed 或移动判据。
