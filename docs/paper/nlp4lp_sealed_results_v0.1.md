## 4. 失败层级与机制边界

1. **作者/晋升泛化不足**：MAMO 上大量候选被保守关闭，依赖独立反例的纠偏无法迁移到 sealed 的无标签环境。
2. **硬 guard 不是免费增益**：可能改变原本正确的求解实现，或者无法修复目标错误；A4 在两条数据线上都没有超过仅软 memory。
3. **旧域资产不可直接迁移**：RetailOpt witness 在新域全部为 schema UNKNOWN，必须重建域资产。
4. **参考噪声影响判据**：MAMO TSP 与 NLP4LP 均存在参考冲突，必须保留原始与独立裁决双口径，不能为追求过线而删样本。
5. **固定检出与业务收益不同**：提高错误检出并未自动转化为端到端正确率提升，且原始误报超过 10%。

本结果否定的是当前“冻结作者 + 独立反例晋升 + 硬 guard”实现的跨域有效性，不否定 memory/CEGIS 在所有形式下的价值。validation 的反例修复只能作为局部机制证据，不能写成通用自进化成功。
