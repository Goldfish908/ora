# 生成端升级:P2 臂(v0.2 先验 + 建模程序脚手架)

日期:2026-11-02。前置:P1 臂(priors_pilot_v0.1.md)证明工具知识先验
消灭 crash(64%→7%)但 pass@1 仅 +1.6pp;ReLoop 同模型对照
(reloop_qwen27b_v0.1.md)显示其 CoT 脚手架单次生成 20.5%,优于我们
零样本 prompt 的 6.8%。P2 臂把两者合并进生成端:v0.2 先验(G1–G10 工具
知识)+ 通用建模程序(理解→形式化→对照题面自查)。

## 1. 方法

- 注入文件:`configs/conventions_priors_v0.2.txt`,在 P1 的 G1–G8 上补
  G9(m.sum)/G10(gurobipy 属性),新增 [MODELING PROCEDURE] 三段:
  ① UNDERSTAND(含"按数据值判断机制激活/非激活");② FORMALIZE(变量
  域 CONTINUOUS/INTEGER/BINARY 显式决策,约束逐条数学陈述);
  ③ VERIFY(约束/成本项/数据键对照题面自查)。
- **防泄题纪律**:脚手架只含通用 OR 方法论,不含任何零售语义约定
  (如初始库存默认值)——语义级先验属第 2 代 memory,需族留出协议,
  本臂不碰。
- 运行:零样本 schema_sol pilot 重跑,同变体同模型 thinking on;
  输出 `runs/m1_pilot_priors2/`。

## 2. 结果(190 细胞,on 模式,witness 可行 + 目标值 match/better)

| 臂 | pass@1 | crash | 幻影 | LLM 耗时 |
|---|---|---|---|---|
| 基线 pilot | 6.8% (13) | 64% (121) | 29% (56) | 130s |
| P1(先验 v0.1) | 8.4% (16) | 7% (13) | 84% (159) | 179s |
| **P2(v0.2+脚手架)** | **11.1% (21)** | 5% (9) | 84% (160) | 140s |
| (参照)ReLoop CoT 单次 | 20.5% (39) | — | 口径仅目标值容差 | 247s |

- guard 规则对 P2 代码重放仅 4 例 G0(语法):v0.2 先验仍被近乎完全遵守;
- 幻影率与 P1 持平(84%):如设计预期,通用方法论不解决隐藏约定问题——
  语义层错误的防线仍在闸门+witness;
- 与 ReLoop CoT 的差距(11.1% vs 20.5%)收窄但未消除,残余差距来源:
  其完整 CoT 推理链更长(247s/题 vs 我们 140s)、数据抽取免除一切转抄、
  以及口径差异(其 39 题中含幻影假阳性,与我们真成功交集仅 3 题)。

## 3. 结论

1. 生成端组合升级有效且近乎免费:pass@1 6.8%→11.1%(+63% 相对),
   LLM 耗时持平——primarily 是 prompt 资产,不增运行时成本。
2. 生成端提升会**抬高整个 harness 的起点**:P2 的 round-1 成功 21 题,
   直接进入后续环的起点池;按 B'' 臂 r2/r3 各 +4~7pp 的边际,
   合体臂(P2 生成 + guard v0.4 + 闸门 + witness 环)预期显著超过
   B'' 的 54.2%。
3. 语义层幻影(84%)是唯一剩余的大头,确认第 2 代 memory(族级语义
   约定先验,需族留出)与 checker-authoring agent 的研究价值。
