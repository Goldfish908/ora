# 自进化最小可行版 v0.1:把 harness 的记忆变成可进化的基因组

日期:2026-11-03
状态:设计评审稿(未实施)
前置:语义记忆第 2 代文档(semantic_memory_gen2_v0.1.md)、
双链集成(ensemble_dualchain_v0.1.md)

## 0. 生死判据(先写死,再动手)

**进化 3 代之后,最优基因组在 F1-F4 的 60 题代际检查集上的单发成功率
必须显著超过手工蒸馏基线(P3 配置的 21.6% 单发 / 对应 F1-F4 切片数字),
且该优势在 F5-F8 留出族(90 题)上不衰减为噪声。**
达不到 → 证明"记忆进化"在这个任务规模上不如手工蒸馏,如实报告负结果,
回到手工+集成路线;达到 → 才允许投入视野 2(检查者共进化)。

## 1. 基因组表示(刻意小)

一个基因组 = 一个目录,4 个槽位,全部离散:

| 槽位 | 取值 | 说明 |
|---|---|---|
| G-code | conventions 文件(v0.2 条款的子集+措辞变体) | 代码工具知识 |
| G-sem | semantic conventions 文件(条款子集+措辞变体) | 领域语义 |
| G-guard | 守卫规则开关向量(G1-G10 子集) | 回路内静态检查 |
| G-repair | 修复提示模板(2-3 个候选措辞) | witness 违例后的反馈话术 |

温度、模型、闸门、witness 一律固定——v0 不进化基础设施,只进化记忆。
每个基因组附 provenance:父代、变异算子、针对的失败类。

## 2. 留出架构(物理隔离,不是纪律)

- **F5-F8(90 题)= 金库**。进化内圈的任何环节接触不到:
  开发切片文件里物理上不存在这些题;变异 LLM 的 prompt 里只放
  F1-F4 的失败记录;参照值只用于适应度打分,永不进入变异 prompt。
- **F1-F4(100 题)再切两层**:40 题分层切片(每族 10 题)= 适应度
  评估集,每代每个基因组都跑;其余 60 题 = 代际检查集,只测
  "每代冠军",用来检测对适应度集的过拟合。
- 全量 190 题:只对最终冠军跑一次,作为对外报告数字。

## 3. 适应度函数

主指标:40 题切片上的单发真成功率(witness 可行 ∧ 目标值 match)。
平局裁决:幻影率低者优先;再平:LLM token 用量低者优先。
(全部是部署态可得的量,参照值只用于 match 判定——与双链仲裁的
"决策无真值"原则一致,此处真值仅作评估,不进决策。)

## 4. 变异算子(4 个,全部留痕)

1. **台账驱动新增**:从最近 N 条失败记录(仅 F1-F4)抽一类失败,
   让 LLM 起草一条新惯例条款,人工一键确认后入库;
2. **措辞变异**:LLM 改写既有条款(保留语义、换表述),为集成
   提供措辞多样性;
3. **条款删减**:删除统计上"零命中"或"误报>命中"的条款
   (数据来自守卫台账的命中/误报计数);
4. **交叉**:两个父代的条款集取并集/交集,产出子代。

## 5. 进化循环(3 代可行性验证)

- 第 0 代:手工蒸馏基因组(P3 配置)为种子 + 7 个变异体 = 8 个体;
- 每代:8 个体 × 40 题 ≈ 320 次 LLM 调用(约 1.5-2 小时),
  选前 2 名精英保留,其余 6 个由变异算子补足;
- 每代冠军跑 60 题代际检查集;第 3 代冠军跑全量 190 题 +
  F5-F8 留出族单独报告。
- 总预算:约 5-6 小时 LLM 时间 + 一次全量验证,CPU 求解可忽略。

## 6. 实现映射(复用已有轮子)

- 单发评估直接复用 `scripts/m1_pilot.py --conventions-file <基因组目录下的文件>`;
- 新增 `scripts/evo_driver.py`:基因组注册表(jsonl 台账)、
  适应度计算、选择、变异算子调度;
- 开发切片:`data/m1_retailopt/dev40_f1f4.jsonl` 与
  `data/m1_retailopt/gapcheck60_f1f4.jsonl`(生成后冻结,入库);
- 守卫开关向量需要给 `guard_check.py` 加 `--rules G1,G3,...` 参数
  (小改动);
- 修复模板槽位在 v0 先只留接口,不打开(减少自由度)。

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 进化内圈过拟合 40 题 | 60 题代际检查集每代测;冠军-检查集落差 >5pp 即报警 |
| 隐性泄题(参照值/留出族信息渗入 prompt) | 物理隔离(§2);变异 prompt 模板代码评审 |
| 8×40 太小,选择信号噪声大 | 每代跑 2 个随机种子取均值;接受"只验证可行性"的定位 |
| 条款膨胀,prompt 变长挤占上下文 | 条款总数硬上限(代码 10 + 语义 10);超限时强制删减算子 |

## 8. 不做清单(v0 明确排除)

- 不进化 witness 规则(那是视野 2,需要对抗者配合);
- 不动 witness 反馈话术的自由度(只留接口);
- 不引入第二种数据集(进化跑通后再说);
- 不动权重(视野 4)。
