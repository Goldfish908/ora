# LLM Formulation 策略 × 可学习求解后端的协同训练
## 分层 World Model 方案设计稿 v0.1（讨论稿，未定稿）

> 本文档基于三轮文献精读（L2 先例组 6 篇、L3 与奖励模型组 6 篇、solver 反馈 RL 与课程组 4 篇）与前期调研（FormuEvo、MILP-Evo、PlanB&B 全文级理解）综合而成。所有标注【决策点】处需要团队讨论拍板。

## 1. 研究定位

**一句话**：在「LLM 生成 MILP formulation → 可学习后端（PlanB&B）/SCIP 求解」的不可微接口上，建立以**实例级 world model（L2）为枢纽**的协同训练系统——求解成本首次进入 formulation 策略的奖励，双向闭环首次在「LLM 策略 × 可学习精确求解组件」之间闭合，弃权架构保证 OOD 鲁棒性。

**三个文献空白的证据链**（本轮精读确认）：

| 空白 | 证据 |
|---|---|
| A. 求解成本从未进入 formulation 奖励 | SIRL（NeurIPS 2025）奖励 = 格式0.5 + 可执行1 + 正确2 + 建模技巧1，无任何时间/节点/gap 项；StepORLM（ICLR 2026）同样只有结果硬标签 + 过程批评；FormuEvo（2026）把成本当适应度但只做一次性演化、LLM 权重不动 |
| B. 双向闭环无人做过 | ACEvo 是程序空间双向（无梯度、solver 端是启发式代码非权重）；MILP-Evo 是 solver 内部两组件的共同设计（非跨 formulation/solver 边界）；SIRL/StepORLM 的 solver 全程冻结 |
| C. 实例级预测模型从未用作 RL reward model | SATzilla→Fischetti→Hendel→Hosny 谱系全部止步于「预测/选择」；没有任何工作把成本预测器当作策略训练的廉价奖励源；反事实标签问题（只观测实际所用后端的结果）在该谱系中未被正面处理 |

**与最近邻居的划界**：
- PlanB&B（Strang et al., AAAI 2026）= 我们的 L1 基底与「B&B 世界模型」的出处，只引不 claim；
- OR-PRM（ICLR 2026）= 步级正确性 PRM，我们做方向级 continuation value 且终端锚定求解成本；
- Pathwise（ICML 2026）= LLM-as-transition-model 免训练搜索，我们学参数化值函数砍掉每步 Na×Nw 次真实评估；
- FormuEvo = problem 级一次性演化 vs 我们 instance 级策略训练 + 后端可学习。

## 2. 总体架构

```
            ┌─────────────────────────────────────────┐
   攻击者 A │ 约束内对抗课程（PAIRED-style regret 信号）│  ← 防塌缩 + 画弃权边界
            └──────────────┬──────────────────────────┘
                           │ 扰动实例分布（DRO 球内）
   ┌─────────┐   formulation   ┌──────────────┐
   │ LLM 策略 │ ──────────────→ │  路由/弃权层   │ ←── L2 元模型（枢纽）
   │  (GRPO)  │ ←──── 奖励 ──── │  B0默认/放行B2 │
   └─────────┘                 └──────┬───────┘
        ↑                       ┌──────┴───────┐
        │ 成本预测(L2打分)        │ SCIP  │ PlanB&B │
        └───────────────────────┤ (B0)  │  (B2)   │
                                └──────────────┘
                                  L1：已验证域内专家
```

- **L1**（PlanB&B）：现状，不改动。定位为「已验证域内的专家后端 + L2 的特征传感器（值头/branchability 置信度）」。
- **L2**（枢纽，本方案核心）：实例/formulation 级元模型。三重身份：路由器（部署）、GRPO 成本预测器（训练）、预算分配器（后期）。
- **L3**（试点）：agent 搜索的方向值函数，CO-Bench 场景，依赖 L2 做终端 bootstrap。
- **攻击者**：PAIRED 式第三方，生成「对手能解、联合系统不能」的实例分布扰动，同时产出弃权边界的训练数据。

## 3. W-A：L2 元模型（第一个建设的工作流，4–6 周 MVP）

### 3.1 数据协议（本项目最独特的资产，必须写进论文）

三层数据来源：
1. **常态化落账**（免费、有偏）：每次 run 记录（实例特征, formulation id, 后端, 配置, 成本, 结局）。存在 bandit 选择偏差——只观测实际所用后端的结果。
2. **重放反事实对**（昂贵、无偏）：W1 A/B 重放设施定期对同一 LP 跑双后端，产生配对成本。这是文献空白 C 的直接回答——SATzilla 靠全量跑所有候选暴力规避，我们用采样重放 + 配对校准。
3. **在线探索流**：5% 实例强制走非推荐后端，维持在线反事实数据流，支撑路由器的持续更新。

### 3.2 特征（三层，成本递增）

- **静态层**（SATzilla 式）：规模、密度、约束类型分布、变量类型比例；计算预算受限（SATzilla 教训：特征成本计入总时间）。
- **探测层**（前 K 节点）：Fischetti 2019 的 37 维运行摘要模板（gap 动态、界改善、树增长、SSG）+ Hendel 2022 的进度信号族（tree weight、leaf frequency 及其 DES 趋势）。
- **学习层**（我们的特色）：PlanB&B 值头在根节点的子树大小预测 + branchability 置信度。L1 的 WM 降级为 L2 的传感器——即使 L1 永远不部署，此通道仍有价值。

### 3.3 预测目标（精读组的关键教训：不预测绝对量）

- **主目标**：相对成本比 log(cost_B2 / cost_B0) 与胜负分类——归一化形式，规避 Hendel 证明的绝对 runtime 高方差问题（其 SOTA 也只有 factor 2–3）。
- **辅目标**：归一化求解进度 γ(t)（Hendel 形式），为后期的 anytime 预算分配打基础。
- **一跑多标签增广**（Fischetti 技巧）：同一次运行在不同截点产生多个训练样本。

### 3.4 模型与验收

- **MVP 模型**：GBDT/随机森林。依据：Hendel 2022 中 RF 优于 GBDT/NN；Fischetti 2019 中 RF/ExT 最优；数据量级（万级行）不支持大模型。
- **后期升级**：TreeGate 式条件化（Zarpellon 2021：全局树状态向量门控调制）处理跨族泛化；Hosny-Reda 式 cost-based 度量学习 + kNN 检索做同族内快速适配，**kNN 距离天然是弃权置信信号**。
- **验收指标（MVP 出门线）**：
  1. router regret vs oracle < 5%（在配对重放测试集上）；
  2. 成本排序 Spearman > 0.8（vs 真实 rollout）；
  3. 校准曲线（预测胜率 vs 实际胜率）；
  4. OOD 探针族上的弃权召回率。

### 3.5 持续学习形态

每晚增量重训（GBDT 分钟级）+ Config Store 式配置/后端结果累积（Hosny-Reda 形态，免重训扩充）+ Way1 retention 机制防止「LLM 策略更新后旧 formulation 区域预测能力退化」。**注意：L2 的非平稳性是策略耦合的**——输入分布被自己的下游消费者（GRPO 更新的 LLM）驱动，这本身就是论文里值得形式化的一点。

## 4. W-B：求解成本感知的 GRPO（奖励共享形态，6–8 周）

### 4.1 奖励设计

```
r = r_exec · r_correct(checker) · (1 + λ · cost_term)
cost_term = clip( log(cost_SCIP / cost_proposed), -c, c )   # 相对 SCIP 的归一化对数比
```

- 正确性门控在前（checker + 执行 + 最优值比对，SIRL 已验证此结构有效），成本项只做乘性整形——**绝不能让成本奖励盖过正确性**（StepORLM 记录的「错误约束碰巧得到正确最优值」案例就是 outcome-only 的教训）。
- cost_term 用 L2 预测打分（批量、廉价），真实 SCIP rollout 抽样校验（Dyna 混合）。
- λ 与 c 为【决策点】，初值建议 λ=0.2, c=2。

### 4.2 抗 Goodhart 机制（Gao et al. 2022 曲线指导）

1. **KL 监控 + 早停**：gold score（真实 rollout 成本）vs KL 距离画曲线，不过峰；
2. **Partial KL**（借 SIRL）：只对 <model>/<code> 段加 KL，推理段不加，保探索；
3. **集成不确定性触发真实评估**：L2 用 ensemble，分歧大的 formulation 强制真实 rollout——LLM 想攻击 L2 的误差就会把自己送进真实评估；
4. **周期性重校准**：每 N 步全量真实 rollout 一小批，校正 L2 漂移。

### 4.3 验收

- 主对比：SIRL 式 correctness-only 奖励（复现其奖励结构作基线）vs 我们的成本感知奖励，同正确率下比 SGM 求解时间；
- 次要：L2 打分 vs 全真实 rollout 的训练效率比（样本成本下降倍数）。

## 5. W-C：bilevel 交替 → co-adaptation（形态 2/3，第二阶段）

### 5.1 交替协议（借 ACEvo 双环 + StepORLM 警示）

- 固定 LLM → 用其真实产出分布增量更新 PlanB&B → 在重放设施上验收（同 LP 跨后端）；
- 固定 PlanB&B → 用新后端反馈更新 LLM（W-B 的 GRPO）→ 验收；
- **每轮交替后在冻结 OOD 探针套件上测双端退化**——StepORLM 记录了共进化的非单调退化（iter2 −4.4%），我们把「探针退化预算」设为交替的停止/回滚门。

### 5.2 防塌缩三件套（精读组的共识防护模式）

1. **对抗课程**（PAIRED 式）：攻击者扰动实例分布，奖励 = 近似 regret（外部参照 solver 能解、联合系统不能的程度），自动把课程压在能力前沿；**现实性约束**：扰动限制在真实任务分布的 DRO 球内（【决策点】：距离度量与球半径）；
2. **多样性保留**：LLM 端在 GRPO 中保留 formulation 风格多样性（熵正则或种群化），ACEvo 消融证明撤掉多样性/变异压力即退化；
3. **冻结外部锚**：一组永参与训练的 held-out 分布族 + 公共基准（MIPLIB 子集），防止「双边互相过拟合后自欺」。

### 5.3 验收门

进入 co-adaptation 的前提（W4 五条门槛的量化）：L2 确认目标分布满足「SCIP 需真实分支 + 同构高频重复 + 预测收益域存在」。攻击者产出的边界数据同步训练路由器的弃权判据。

## 6. W-D：L3 专家迭代试点（第三阶段，CO-Bench 床）

### 6.1 场景与设定

- **床**：CO-Bench（arXiv:2504.04310，公开，36 题，10 秒/实例单核，64 步 agent 预算）。该基准中**超时是头号失败模式**——方向值必须预测「预期运行成本」而不只是解质量，这恰是我们相对 PRM 谱系的差异点。
- **状态**：部分解（候选算法代码 + 自然语言 idea + 结构特征）；**动作**：方向级修改算子（借 Pathwise 的「父集 + 推导指令」抽象，不学 token 级）；
- **值**：预算约束下的期望终端归一化得分（objective/reference）。

### 6.2 训练信号（L2 依赖在此）

- 终端评估 = L2 预测的成本/gap bootstrap（MVE 式）+ 真实执行锚（借 OR-PRM 的共识过滤控噪：执行结果 + 校验双源一致才入库）；
- 标签源两级漏斗（借 LLM4Branch）：快速子集检查 → 昂贵全集评估，值函数学「快筛分数 → 终端得分」的映射；
- **不对齐专家、只对齐终端成本**（LLM4Branch 的 24.72% 教训：与 strong branching 一致率极低却全面超越模仿学习）。

### 6.3 基线与验收

- 基线：FunSearch（CO-Bench 现最强 0.842）、Greedy Refine/EoH（0.840）、Pathwise 式无值函数搜索；
- 主指标：同评估预算下的 Avg Score 与 Valid Solution %；次要：达同等分数所需的真实评估次数（值函数的样本效率收益）；
- Goodhart 防护同 W-B（值函数被搜索过度利用是必然，KL/早停/集成三件套复用）。

## 7. 实验协议

### 7.1 目标分布选择（【决策点】）

候选（按优先级）：
1. **SCUC/电力机组组合类**：Xavier-Qiu-Ahmed 先例 + PlanB&B 作者的 EDF 水电动机，天然「难求解 + 高频同构重复」；
2. **Ecole 四族的新难度体制**：MIS 已饱和（W1 证据），选 SC/CA/FL 的更大规模或新参数区；
3. **CO-Bench 子集**：L3 试点专用。

### 7.2 基线矩阵

| 维度 | 基线 |
|---|---|
| 建模器 | Qwen 直出、SIRL 式 correctness-only 奖励、FormuEvo 式演化（同预算） |
| 后端 | SCIP 默认（B0）、PlanB&B（B2，含带/不带 Gumbel Search 两档——W1 遗留问题） |
| 路由 | 静态规则、SATzilla 式特征回归、我们的 L2（含弃权） |

### 7.3 指标

SGM 求解时间（1s shift）、正确率（checker + 最优值比对）、router regret、OOD 探针退化幅度、训练样本成本（真实 rollout 次数）。

### 7.4 关键消融

L2 特征三层逐层去除；反事实配对数据 vs 纯落账数据；混合奖励中真实 rollout 比例扫描；攻击者有无（co-adaptation 塌缩对照）；弃权召回率-误放行率权衡曲线。
