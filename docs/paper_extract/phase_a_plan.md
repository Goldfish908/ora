## Step 7 — A+B0 测试（两层，逻辑显式）

### 7a 管道冒烟（本阶段内，探索级，小预算）
**目的：验证在线环路的机械正确性，不出科学结论。**

环路设计：
```text
每步：A（模型）一次提出 K 个候选
   → B0（R1 级 GBDT，允许很弱）对 K 个候选排序
   → 真实评价 E 只执行 Top-m（m < K）
   → 反馈回注，进入下一步
```

核验点（全部是机械正确性）：
- [ ] 账本口径正确：预算按**真实评价次数 m** 扣减，K 次提议不计真实预算；
      LLM 调用成本单独记辅助账
- [ ] B0 入环的特征构造与离线探针同源（as_of_seq=t 防泄漏不变量在在线环里同样成立）
- [ ] 被 B0 过滤掉的 K−m 个候选**留档不评价**（标 filtered_by_b0，不进账本、
      不进反馈，但进数据资产——它们是事后审计 B0 误杀率的原料）
- [ ] 环路在 budget 耗尽/模型停止时正确终止

### 7b 结论实验（本阶段外，A1 数据落账 + R2/R3 有信号后，结论级）
**目的：回答 MVP 核心假设——相同真实评价预算下 A+B 优于 A。**

对照设计（预登记；2026-08-19 因果混淆修订，用户裁决）：
- **共同候选生成器**：同一状态 → 同一个 A → 生成相同 K 个候选；
  **只换选择器**——对照臂：原始顺序 / 随机 / 规则选 Top-m；
  实验臂：B0 选 Top-m
- 控制：两侧真实评价预算严格相等、LLM 调用数与候选集合相同；
  模型、采样、harness 其余全部一致（单一变量 = 选择器）
- ProposedMethod 保留为**系统级参考臂**，但不再是唯一因果对照
- 主指标：固定预算下 best score；达到同分数所需真实评价次数；
  B0 误杀率（filtered_by_b0 候选的事后抽验）；分问题类的负迁移
- 判定：预注册效应量 + 足够重复（结论实验纪律），结果即
  **MVP 首个可复现核心结果**
