# M2 受控最小对照集设计 v0.1（go/no-go 闸门载体）

日期:2026-10-29。依据:motivation_study v0.2(§M2、§8.6 规模反推)+ 任务书 v1.1 §14.2/§14.4。
定位:**发展性先导**(development),不进入确认性测试;确认性留出结构在生成器、变异、witness、修复目标中均不出现(§14.2)。

## 1. 设计目标

回答 P2(超额失败)与 P1 的连接占比(受控侧),要求:

1. **程序可归因**:每题配原子对应题、连接翻转对、witness,错误分类不依赖 LLM 标注;
2. **难度旋钮在连接上**:模块内部简单到 8B 模型几乎不错,区分度来自连接关系;
3. **统计功效**:超额失败 ≥5pp 可检出 → 60–80 个组合问题、每题 8 采样(§8.6)。

## 2. 表示:类型化 JSON 三层(沿用 dsl_fitgap 定稿)

```json
{
  "modules":     [{"id": "inv_balance", "expr": "...", "ports": [...]}],
  "instances":   [{"name": "IB1", "module": "inv_balance", "bind": {...}}],
  "connections": [{"from": "IB1.out", "to": "CAP1.in", "direction": "flow",
                   "activation": "always|cond(y[i])", "time_index": "t|t+1"}]
}
```

两层防失真(§14.4):schema 不替模型补全答案连接;必须允许"类型合法、模块各自有效、整体连接语义错误"的输出,且能被独立 checker 识别。**编译器与 checker 不共用同一个连接解释函数**——编译器从 JSON 生成 PySCIPOpt 模型,checker 从规格文本独立实现规则检验(小规模整数问题用枚举/直接规则检查)。

## 3. 规则模块库(8 个,均为教科书原子)

| 模块 | 语义 | 典型端口 |
|---|---|---|
| M1 库存平衡 | 期末库存=期初+流入-流出 | in/out/期初 |
| M2 容量上限 | 资源占用 ≤ 容量 | 占用量/容量 |
| M3 需求满足 | 服务量 vs 需求(可缺货罚) | 需求/服务 |
| M4 流量守恒 | 节点流入=流出 | 入边/出边 |
| M5 指派唯一 | 每对象至多/恰好一个槽 | 二分两侧 |
| M6 时间窗 | 开始/结束/先后关系 | 区间端点 |
| M7 预算约束 | 加权和 ≤ 预算 | 费用/权重 |
| M8 目标项 | 成本/利润项接入目标 | 系数/变量 |

## 4. 连接算子库(4 类,即变异轴)

| 算子 | 正确形态 | 典型错误形态(变异用) |
|---|---|---|
| **C1 绑定** | 模块端口接对变量/集合 | 绑到平行变量(P1 需求接 P2 库存) |
| **C2 方向** | 流入/流出、读/写正确 | 退货记为流出 |
| **C3 激活** | 条件触发的约束带激活 | 恒生效/恒失效(漏 big-M 或反接) |
| **C4 时间/索引** | 跨期对齐(期初[t]=期末[t-1]) | 偏移一格、错层(产品/地点串位) |

## 5. 题目生成与翻转对

- **源结构**:8 模块取 2–3 个组合,每个组合配 1–2 条连接 ⇒ 结构目录约 24–40 个;
- **每结构展开**:数值/措辞实例化 2–3 个 ⇒ 60–80 个组合问题(**统计口径分开报**:独立结构数 / 源问题数 / 数值实例数,§14.2);
- **原子对应题**:每个模块单独成题(同数据规模),测 P(原子对);
- **翻转对**:同一题面只改一条连接的关系(如 t→t+1、流入→流出、条件激活→恒激活),且**必须存在能区分两种关系的合法实例与决策**(独立确认);题面不得出现答案连接 ID;
- **witness**:每个变异配可执行 witness(具体输入下违约的可观测证据),受控变体的变异标签自动获得。

## 6. 测量与判定(对接 motivation §5)

1. 原子/已见组合/未见组合的语义通过率 + 可解析率/可编译率(四组分开);
2. 自然生成提交的已确认连接缺陷率,**双分母**:全部分母 + 局部规则已核验正确子集;
3. 错误归因五桶:模块内部 / 连接 / 混合 / 其他 / unknown(不许强行归类);
4. 超额失败 = P(组合失败) − [1 − Π P(原子对)],按源结构聚类 bootstrap,95% CI;
5. 翻转对一致率:连接表述翻转时实现是否随之翻转。

## 7. 生成器架构(扩展现有 controlled/)

```
m2gen/
  spec.json          # 结构目录:模块组合+连接+翻转定义(人工编写,一次)
  instantiate.py     # spec → 数值实例(随机种子固定)
  emit_problem.py    # → problem.md(题面,无答案连接 ID)
  emit_reference.py  # → reference.py(PySCIPOpt 正确实现,从 spec 编译)
  emit_mutants.py    # → mutants/(C1–C4 变异,标签自动)
  emit_witness.py    # → witness/(每变异的可执行反例)
  checker.py         # 独立语义 checker(不 import 编译器)
```

现有 controlled/ 三题是手工版五件套;m2gen 把它参数化。手工三题保留为生成器的**回归测试**:生成器输出必须与手工制品语义一致。

## 8. 不做清单(范围护栏)

- 不做通用建模语言;连接只开放 C1–C4 四类;
- 不支持任意 Python/非线性表达式;
- 本批全部 development;确认性留出结构另行生成、另行封存;
- 不用 LLM 生成题面初稿后再人工改——题面从 spec 模板渲染,保证标签正确性。
