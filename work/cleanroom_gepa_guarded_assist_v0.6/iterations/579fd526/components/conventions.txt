## Critical PySCIPOpt 6.3.0 API Rules (MUST FOLLOW)

These are the EXACT method signatures available. Using incorrect signatures will cause crashes:

### Objective and Optimization Direction
- `model.setMinimize()` — takes ZERO arguments. It simply sets the model to minimize. Do NOT pass any argument to it.
- `model.setObjective(expr, sense='minimize', clear='true')` — use `sense='maximize'` for maximization problems. This is the CORRECT way to maximize.
- **NEVER write `model.setMinimize(False)` or `model.setMinimize(True)`** — this will crash with `TypeError: setMinimize() takes exactly 0 positional arguments (1 given)`.
- For maximization: either use `model.setObjective(expr, sense='maximize')` OR negate all objective coefficients and use `model.setObjective(expr, sense='minimize')`.

### quicksum
- `quicksum` is a MODULE-LEVEL function imported via `from pyscipopt import Model, quicksum`.
- It is NOT a method on Model. Do NOT write `model.quicksum(...)`.
- Usage: `quicksum(coeff * var for ...)` or `quicksum([coeff * var, ...])`.

### Getting Solution Values
- `model.getVal(var)` — returns the value of a variable in the best solution. CORRECT.
- `model.getVarVal(var)` — DOES NOT EXIST (AttributeError).
- `model.getObjVal(original=True)` — returns the objective value. CORRECT.
- `model.getObjval(...)` — DOES NOT EXIST (wrong case, AttributeError).

### Status and Solution Count
- `model.getStatus()` — returns a string like 'optimal', 'gap', 'timelimit', 'bestsollimit', 'infeasible', 'nodelimit'. CORRECT.
- `model.getOrigStatus()` — DOES NOT EXIST.
- `model.getNSols()` — returns number of solutions found. CORRECT.
- `model.getNsolns()` — DOES NOT EXIST.

### Parameters
- `model.setParam(name, value)` or `model.setRealParam(name, value)` — set SCIP parameters.
- Relative gap: `model.setParam("limits/gap", 0.0005)` (this is the standard SCIP parameter name).
- Time limit: `model.setParam("limits/time", 300.0)`.
- `model.getRealParam(name)` — get a parameter value.

### Variable Bounds
- `model.chgVarUb(var, ub)` — change upper bound. CORRECT.
- `model.chgVarLb(var, lb)` — change lower bound. CORRECT.
- `model.setUb(var, ub)` — DOES NOT EXIST.
- `model.setLb(var, lb)` — DOES NOT EXIST.
- `var.getUbGlobal()` and `var.getLbGlobal()` — exist on Variable objects (not on Model).

### Other
- `model.fixVar(var, value)` — fix a variable to a value.
- `model.hideOutput()` — suppress SCIP console output.
- `model.addVar(name='', vtype='C', lb=0.0, ub=None, obj=0.0, ...)` — add variable. vtype: 'C' (continuous), 'I' (integer), 'B' (binary).
- `model.addCons(cons, name='', ...)` — add constraint. `cons` is a comparison expression like `expr <= value` or `expr >= value` or `expr == value`.
- `model.optimize()` — solve the model.
- `model.free()` — free model resources.

## Common Pitfalls to Avoid

1. **Never call `model.setMinimize(False)`** — use `model.setObjective(expr, sense='maximize')` instead.
2. **Never call `model.getObjval()`** — use `model.getObjVal()` (capital V).
3. **Never call `model.getVarVal()`** — use `model.getVal(var)`.
4. **Never call `model.getNsolns()`** — use `model.getNSols()`.
5. **`quicksum` is a standalone function**, not a model method.
6. **For maximization with setup/fixed-charge costs**: the objective coefficients for setup variables should be NEGATIVE (since you're maximizing profit and setup costs reduce it), OR negate the entire objective and minimize.
7. **Big-M values**: use tight Big-M values where possible. For capacity constraints, use the actual capacity as Big-M rather than 1e6.
8. **Rounding**: when extracting integer variables, use `int(round(model.getVal(var)))`. For continuous variables, round to 8 decimal places.
9. **Time limit**: always check `os.environ.get("ORCLAW_SOLVE_TIME_LIMIT_SECONDS")` and cap at 300s.
10. **The solver must run from scratch**: `python /app/submissions/solve.py` must read data, build the model, solve, validate, and write all output files in a single execution.
