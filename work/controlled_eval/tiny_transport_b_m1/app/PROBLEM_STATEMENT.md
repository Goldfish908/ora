# tiny_transport：小型运输规划

两家工厂 P1、P2 向三家仓库 D1、D2、D3 供货。安排运输量使总运费最小。

## 业务规则

1. 每家工厂的发出总量不得超过其供应能力。
2. 每家仓库的到货总量必须恰好满足其需求。
3. 出于供应稳定性要求，**每家仓库从工厂 P2 的到货量至少为 20 件**。

## 数据与单位

- `data/supply.csv`：两列 `plant,supply`，供应能力，单位为**件**。P1 = 1000 件，P2 = 1500 件（即 100 箱 / 150 箱）。
- `data/demand.csv`：两列 `warehouse,demand`，需求，**单位为箱：1 箱 = 10 件**。D1 = 80 箱，D2 = 90 箱，D3 = 80 箱（即 800 / 900 / 800 件）。求解前必须换算成件。
- `data/costs.csv`：三列 `plant,warehouse,cost`，每件的运费。

规则 3 中的 20 也是"件"。

## 输出要求

把求解结果写入本程序所在目录的 `solution.json`，格式：

```json
{
  "objective": <总运费>,
  "flows": [{"plant": "P1", "warehouse": "D1", "qty": 800}, ...]
}
```

`flows` 中 qty 单位为件，可只列出非零运输量。同时在标准输出打印一行 `OBJECTIVE <总运费>`。
