# 代理信号放大曲线

所有指标由官方运行制品重算。横轴包含 seed 和完整验证候选，不是仅全局改进候选，也不是所有被拒绝提议。
主幻影指标为 phantom_proxy/proxy_match：弱代理通过但独立强检查失败。普通不可执行或代理未通过不混入该指标。
完整分母 N 用于曲线；observed 排除生成/基础设施错误，truth observed 另排除 UNKNOWN。覆盖不完整时不得把缺失当成真实负例。
